# Chrome 网上应用店文案

## 名称

BlueNoise - 让 X 重新值得阅读

## 简短说明

用本地、可逆的关键词规则模糊或隐藏嘈杂的 X 回复；不调用 API、不读取 cookie，也不修改账号。

## 详细说明

BlueNoise 让 X 的回复区更容易阅读，但不会替你操作账号。它按照关键词规则将命中的
回复模糊或隐藏，不刷新页面，不改变 X 设置，也不改变你的账号状态。

### 可以做什么

- 仅在推文详情页按内置、社区和个人词库过滤回复。
- 支持普通关键词及 `/正则/flags` 自定义规则。
- 识别空格、零宽字符等常见拆字规避。
- 支持模糊或隐藏，并可通过白名单纠正误伤。
- 新加载的回复自动处理，无需刷新页面。

### 不会做什么

- 不读取 cookie，不调用 X API。
- 不拉黑、静音、关注、取关、发帖或修改 X 账号。
- 不过滤你点开的主推文，只处理其回复。
- 不收集分析数据，也不会将你的规则上传到服务器。

### 权限说明

- `storage`：仅在浏览器本地保存设置、规则和白名单。
- `raw.githubusercontent.com`：仅在首次获取或你手动同步词库时下载公开词库。
