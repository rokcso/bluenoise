# Chrome 网上应用店文案

## 名称

BlueNoise - 让 X 重新值得阅读

## 简短说明

用本地、可逆的关键词规则模糊或隐藏嘈杂的 X 回复与时间线推文；不调用 API、不读取 cookie，也不修改账号。

## 详细说明

BlueNoise 让 X 的回复区和首页时间线更容易阅读，但不会替你操作账号。它按照关键词规则
将命中的回复或推文模糊或隐藏，不刷新页面，不改变 X 设置，也不改变你的账号状态。

### 可以做什么

- 在推文详情页过滤回复，并在首页时间线过滤推文，使用内置、社区和个人词库。
- 按数字 ID 或 @用户名屏蔽具体账号，使用内置社区账号名单，也可自建本地黑/白名单。
- 支持普通关键词及 `/正则/flags` 自定义规则。
- 识别空格、零宽字符等常见拆字规避。
- 支持模糊或隐藏，并可通过白名单纠正误伤。
- 新加载的回复与推文自动处理，无需刷新页面。

### 不会做什么

- 不读取 cookie，不调用 X API。
- 不拉黑、静音、关注、取关、发帖或修改 X 账号 —— 被屏蔽的账号仅在本地被模糊或隐藏，不会在 X 上产生任何操作。
- 在推文详情页不会过滤你点开的主推文，只处理其回复；时间线推文与回复一样参与过滤。
- 不收集分析数据，也不会将你的规则上传到服务器。

### 权限说明

- `storage`：仅在浏览器本地保存设置、规则和白名单。
- `raw.githubusercontent.com`：仅在首次获取或你手动同步词库时下载公开词库。
